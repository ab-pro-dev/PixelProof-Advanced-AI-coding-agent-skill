Zero-Config Pipeline

The Mandatory 8-Step Workflow

PixelProof enforces a deterministic verification loop that prevents AI agents from claiming premature success.

Step 01

Auto-Discover References

Drop images into references/. The agent inspects dimensions, infers routes, and writes references.json automatically.

Step 02

Inspect Project Stack

pixelproof inspect analyzes framework (React, Next.js, Vue, HTML), package manager, scripts, and styling in read-only mode.

Step 03

Analyze Visual Tokens

The agent writes design-spec.md mapping typography, layout grids, colors, margins, and component boundaries.

Step 04

Implement Code

Agent crafts frontend code matching project architecture and starts the local dev server.

Step 05

Capture Localhost

pixelproof capture uses headless Playwright Chromium to photograph exact viewports with deterministic rendering.

Step 06

Compare & Rank Diff

pixelproof compare --regions computes MAE, differing pixels, diff masks, and ranks 4×4 regions by defect priority.

Step 07

Iterate & Refine

pixelproof iterate tracks deltas vs previous run, detecting stalls and visual regressions until the page matches.

Step 08

Verify & Audit Report

pixelproof report produces audit-ready Markdown and JSON evidence strictly separating measurements from claims.

Command Matrix

Built-in CLI Commands

Uniformly available through pixelproof <command> or npx pixelproof-ui <command>.

Command Usage & Flags Description
doctor pixelproof doctor [--json] Inspects Node >= 20, Python >= 3.12, Pillow, NumPy, and Chromium launchability.
install-skill pixelproof install-skill [--agent <name>] Configures AI agent instructions for Antigravity, Claude, Cursor, Copilot, OpenCode, Codex.
init pixelproof init [--dir <path>] Optional scaffold for starter references.json and configuration.
validate pixelproof validate --manifest <path> Validates manifest schema, viewport bounds, and image readability.
inspect pixelproof inspect --project <dir> Read-only framework and script detector (React, Next.js, Vue, HTML).
capture pixelproof capture --manifest <path> --out <dir> Takes deterministic Playwright screenshots across registered routes.
compare pixelproof compare --reference <p> --actual <p> --regions Computes MAE, differing pixels, and 4×4 regional defect priority scores.
iterate pixelproof iterate --manifest <p> --actual-dir <d> Computes delta comparisons against previous iterations in iterations.json.
progress pixelproof progress --state <path> Detects stalls, regressions, and stop conditions in read-only mode.
report pixelproof report --summary <path> --out <dir> Generates audit-ready Markdown and JSON evidence reports.
